# ShopSphere

ShopSphere is an enterprise-style e-commerce and order management
backend built with Java and Spring Boot.

## Architecture

ShopSphere is designed as a modular monolith with clear domain
boundaries.

## Core Modules

- User & Authentication
- Product Catalog
- Inventory
- Shopping Cart
- Orders
- Payments
- Coupons
- Reviews
- Notifications
- Administration

## Technology Stack

- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA
- PostgreSQL
- Spring Validation
- Maven
